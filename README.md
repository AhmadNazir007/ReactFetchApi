# ReactFetchApi

This is a small React app that fetches GitHub users from the GitHub API and displays them as cards.

## Run locally

1. Install dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm run dev
```

3. Open the app in your browser:

```text
http://localhost:5173
```

## Deploy on Vercel

This project is ready for Vercel deployment. Set the build command to:

```bash
npm run build
```

and the output directory to:

```text
dist
```
